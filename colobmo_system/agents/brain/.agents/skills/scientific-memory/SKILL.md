# Brain: On-Demand Use of Scientific Memory

By default, read the current Memory through builtin `scientific_memory(mode, arguments_json)`. Use overview/browse to discover mechanisms when needed, and search directly for a known need. Global browsing does not require an Atlas ID; mechanisms from other TASKs may suggest transfers. Search cards recommend reading but do not establish applicability; a missing entry does not establish that a result does not exist.

Select a small set of materials addressing a specific obstacle in the current live bracket. After reading complete rules/statements and conditions, pass pinned refs, necessary snapshots, variable mappings, and outstanding transfer obligations to the Cell. Preserve the task's specified oracle/metric/guarantee/resource; directory labels do not replace mathematical definitions.

Explicitly use include_leads=true during discovery and false when formal records are required. Do not treat leads as certified evidence. Save application records for materials actually used; do not forward the whole library or complete search history. If Long-Term Memory yields no match, use external search or original derivation. Do not automatically start Curator/Reviewer or publish memory within the proof loop.

See `GUIDE.md` for detailed rules and actual parameters. This guide is installed with the role's instruction pack.
