# Small-Batch Extraction

1. Verify the paper title, authors, version, and original location; use only tool-computed byte hashes for Source hashes.
2. Read the target contribution's definitions, standing assumptions, Algorithm or Construction, statement, and necessary proof.
3. Select a few knowledge objects with complete dependencies: executable core rules, independently useful conclusions, information restrictions, or transferable methods.
4. Use `overview/browse/search/read/expand`: first check for duplicates using names/aliases and source+locator, then examine neighboring mechanisms and statements.
5. Decide whether to add a source, add a Theorem, add a variant, add a proof, or create an entry. If equivalence is uncertain, use related rather than forcing a merge.
6. Algorithm records retain core queries/updates, initialization, output, public tuning information, operation costs, components, and limitation categories.
7. For Hard Families, separate construction, oracle realization, and coverage; preserve the information-to-error bridge and possible access capabilities that defeat the construction.
8. Theorems must expand key conditions and quantifiers; complexity claims retain oracle/algorithm coverage/output/metric/guarantee/resource/regime/constant dependence.
9. Extract facets from actual content and bind role/subject/scope/evidence/state. Separate shared conditions from variant-specific conditions.
10. Use tags describe research goals and methodological leads only; they do not promise successful transfer. Give each item a realistic use_when and a nearby case prone to misuse.
11. Return a small batch using the runner's schema. `records_json` is only the CLI structured-output transport envelope; its contents must be a valid array of canonical objects.
12. Repair omissions and scope errors; source concerns may be accurately recorded with usage restrictions, without pretending to resolve them. Do not automatically elevate evidence status.

A suggested batch contains 2–6 items from one source; this is not a claim of complete coverage. Leave anchors outside the current scope in remaining.
If formula parsing, subscripts/superscripts, quantifiers, or page numbers appear corrupted, inspect the original pages. Explicitly defer the affected field if image-reading capabilities are unavailable.
