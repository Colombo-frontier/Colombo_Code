# Atlas native backend

This source dependency supplies the native transaction, immutable source, provider, and resource APIs used by Atlas_renew. Its scientific and schema contracts are retained with the renewal component.

Install it together with Atlas_renew in a dedicated virtual environment. This package and Literature_grounded_discovery both provide the `oracle_atlas` namespace and must not be installed together in that environment. This dependency does not modify the sibling component or any Atlas data.

The backend contains general code and required role/schema resources. It includes no local profiles, run history, model credentials, or bundled wheel. Protocol format markers and source-version identity remain part of the APIs.
