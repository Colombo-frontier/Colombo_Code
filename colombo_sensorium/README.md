# Colombo Sensorium

This directory bundles the following Sensorium components:

| Directory | Contents |
| --- | --- |
| [Complexity_altas](Complexity_altas/README.md) | Native records for 445 settings, scientific history, 30 local manuscript entries, static browsing pages, and PDF/TeX/Markdown exports |
| [Structural_exploration](Structural_exploration/README.md) | Independent setting-neighborhood discovery, research, review, and explicitly authorized Atlas publication tools |
| [Literature_grounded_discovery](Literature_grounded_discovery/README.md) | Literature discovery, setting extraction, independent bound review, and transactional Atlas maintenance |
| [Atlas_renew](Atlas_renew/README.md) | Bounded maintenance of existing setting profiles, joint bracket analysis, independent review, and native Atlas adoption |

The spelling `Complexity_altas` matches the source directory. Each component keeps its existing scientific identifiers, data contracts, entry points, and review/publication requirements.

## Current contribution coverage

The **445 settings** form the full Atlas inventory. Adopted Colombo contributions cover **84 settings**: **49** settings attributed to public arXiv papers plus **36** settings using retained local manuscripts, minus **1** shared setting. **2 pending attributions** remain available for review and are excluded from this adopted count.

The **★ Colombo** badge identifies an adopted contribution in the stated comparison scope, independently of the mathematical status label. It can accompany a partial improvement with an unresolved gap. The former **39-setting near-optimal highlight subset** is narrower than this contribution view.

The source registries contain **22 public arXiv paper entries and 30 local manuscript entries**. These counts require work-level deduplication before they can describe distinct research works. N01, A4 and U10 are retained with manuscript-specific contribution scopes on their setting pages and profile downloads. The accompanying paper's historical **more than fifty settings / 56 research works** statement remains separate from the current coverage count; see the [repository overview](../README.md#current-contribution-coverage).


The [Atlas](Complexity_altas/README.md) includes native records, a local static browser, source provenance and complete profile exports. The other components retain separate research, review and publication workflows described in their component guides.

## Sources and data

The Atlas and structural exploration components originate from the [Sensorium source tree](https://github.com/HaihanZhang2001/Colombo_Code). Scientific identifiers, citations and review limitations remain part of the data. The distribution excludes workstation credentials, local runs, test output and environments.
