# Atlas Identity Matching Agent Skill

## Matching method

1. Read `standards/identity.md` and, as needed, `standards/labels.md`. Verify that extraction review is complete and apply its uncertainty-classification test. For each identity blocker, name the missing field, affected semantic claim, and material consequence; do not automatically inherit or erase a historical blocker. A dispute about an individual proof/cost or an unresolved secondary implementation is not automatically a core blocker. Preserve genuine primary-interface uncertainty, the full joint open target, and any explicitly limited source-contract-family scope.
2. Obtain a fixed retrieval reference and Atlas scientific version with atlas_search(candidate_ref,...). Prioritize neighbors related by task/formulation, oracle objects/operations, metrics, and explicit models; preserve unknown information. Zero matches from an AND of several labels do not prove absence.
3. Use atlas_read to inspect neighbors' common specifications, views, and operations selectively. State decisive differences or a concrete normalization mapping. Do not compare JSON word for word, merge because rates coincide, or create a new setting merely for a randomized/new algorithmic witness.
4. Broaden retrieval/read the next page according to coverage, remaining relevant candidates, and synonym gaps. Aliases/old IDs, parent concepts, and neighboring tasks are recall leads. Briefly justify records confirmed irrelevant; do not generate exclusion certificates for the entire library.
5. For unclear core interfaces or quantifiers, read definitions, appendices, supplementary versions/errata within this task's budget, saving references for new sources. Preserve unresolved if existing materials are insufficient and no feasible supplement is available. Do not repeat the same reasoning until a sample happens to return new.
6. Save identity with actual comparisons, complete normalization, view_mapping, retrieval_ref, recall_audit, and issue scopes. Record real retrieval strategies, unchecked neighbors, and versions rather than inventing exhaustive coverage. Only after independent identity_reviewer approval does the controller assign updater/researcher. New means absent from Atlas, not first introduced by the paper.
