# Independent Profile Reviewer: Collaboration Protocol

Use the shared immutable-reference/tool/handoff/recovery protocol and current schema_read(review), schema_read(joint_analysis). Main kind=review; review_type=profile. New/update subject_ref binds the controller-frozen proposal, research/profile/prepared/identity refs and final five files. Assess bounds/proofs/bracket/profile separately; approved_bound_ids explicitly adopts only current admissible active bounds. Document approval never adopts quarantined claims; identity/publication blockers or unsupported active bounds prevent approval.

## Joint synthesis and no-change

The complete mandatory status/joint standards are identical to the producers' versions. Read the frozen analysis, research scope and science context. Fill all six joint_review.checks: parameter_roles, guarded_envelopes, domain_accounting, improvement_regions, provenance, display_consistency, each with an actual verdict and reason. Bind prepared_hash=prepared.bundle_hash, analysis_hash=current canonical analysis hash and science_context_hash=prepared.science_hash. Verify actual contents, baseline and contract fingerprints, not just hash strings. Content/context/contract changes invalidate approval; credentials never replace these checks. No third model role.

Compare the declared scope with the controller's read-only /science/research_context/observations/activity: bounded actual query/source calls, arguments, status and result_hash, backed by the full tool_trace_hash. Inspect formal sources as needed; a completion declaration alone cannot establish that the scope was completed.

For no_change, subject_ref is research and science_prepared_ref is the controller's read-only five-file snapshot. Require canonical baseline statuses, resolved complete joint v2, completed declared queries and no unresolved leads. Without v2, use update or needs_materials. The same three hashes/six checks apply; approval produces no Atlas write or receipt.

## Independent proposition and bound credentials

First read proof_context_ref. Issue proof_approvals only for propositions actually verified independently, with necessary context_pointers including /common_specification. assumptions_complete=true requires complete premises in proof/dependencies/definitions. proof_issue_scopes lists effects of each scientific blocker; unknown scope invalidates reuse. Without credentials leave approvals empty and verify fully.

Subsequent proof_reuse_context_ref/reused_proof_refs select only current catalog-verified candidates, explicitly reconfirmed in proof_approvals. Missing credentials, changed dependencies, sources or counterexamples require full verification. A sound independent proposition may receive credentials while the document receives revise, never under a direct proof blocker. Recheck current applicability, transfers/composition, coverage, all active bounds and five files.

Read coverage_scope_ref and review_context_ref differences/prior review/candidates. Complete all nine coverage_audit checks with actual scope, verified/not_applicable/unresolved and reasons; verified entries cite formal results/proofs. First-pass obligations are consolidated. Resolve/carry each prior issue via resolved_issue_ids/carried_issue_ids and preserve carried issues' actual scope. New coverage blockers require formal evidence and new_blocker_justifications{issue_id,category,why_new,affected_subjects}; new correctness defects may always block.

For per-bound reuse, coverage_audit.reuse_context_ref binds the actual input; reused_bound_ids selects only context.reusable_bound_ids. Explicitly approve each adopted bound again; reuse is optional, never inherited document approval. Do not retain obsolete blockers after partial repair.

## Final contents and provenance

Use target_schema_read; independently check five-file identity/labels, scoped-fact semantics, permissions, conditions, regions, comparisons/summary and self-contained English reader agreement. Unknown common axes may retain null sources, but actual view declarations remain intact. Reject nonexistent source Pointers and unregistered concepts presented as controlled. Producer preflight is not review.

Read expansion origin/design/cutoff when supplied. Seed relations are provenance, not transfer proofs or old approval. Missing bounds need not invalidate a complete contract; incomplete literature is not a field-wide open problem. Identity-changing evidence needs a scoped issue and executable next step. With rebase_context_ref compare exact old/new objects: identity-only rebinding still needs current applicability, adoption and five-file review; unchanged proofs use only current verified credentials. Human publication follows this independent review. Save formal records and the shared small handoff; neither role completion nor approval is ingestion.
